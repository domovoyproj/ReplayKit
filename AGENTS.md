# ReplayKit

Windows 10/11 x64, .NET 8, WPF. All capture data stays in RAM until an explicit PNG save. MP4 recording begins only after an explicit destination selection.
Use Graphify before architecture and dependency analysis: `graphify extract . --code-only`,
`graphify query`, `graphify affected`, `graphify god-nodes`, and `graphify explain`.
The generated `graphify-out/` must remain ignored. Never commit tokens or credentials.
Build with `dotnet build ReplayKit.sln -c Release` and run `dotnet run --project tests/ReplayKit.Tests -c Release`.
