ReplayKit 1.0.1 — локальная история экрана за последнюю минуту для Windows 10/11 x64.

Исправлен стиль живых окон: собственная рамка, прозрачность, цвета текста и шрифты применяются явно. Проверки включают свойства всех трёх окон и смену темы.

- DXGI Desktop Duplication, JPEG 88% в RAM, до 60 кадров, один кадр в секунду.
- Замороженная история, таймлайн, превью, выбор монитора, PNG и буфер обмена.
- Редактор: перо, стрелка, рамка, маркер, непрозрачное скрытие, текст, обрезка, отмена и повтор.
- Настраиваемые глобальные клавиши, трей, запись/пауза, автозапуск.
- Светлая, тёмная и системная темы, Per-Monitor DPI.

`ReplayKit-1.0.1-Setup-x64.exe` — установка для текущего пользователя без прав администратора.
`ReplayKit-1.0.1-win-x64.zip` — portable self-contained сборка, запускайте ReplayKit.exe.
Для portable версии автозапуск можно отключить в настройках.

Изображения не записываются на диск до явного сохранения. Настройки хранятся в `%LOCALAPPDATA%\ReplayKit\settings.json`.
Приложение и установщик не подписаны сертификатом издателя. Защищённый контент и secure desktop Windows не захватываются.
