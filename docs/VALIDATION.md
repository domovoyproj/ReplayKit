# Проверка ReplayKit 2.0.0

Проверено 6 октября 2026 года. Локальная среда: Windows 11 Pro, build 26200, .NET SDK 8.0.425.

## Сборка и автоматические проверки

Сборка Release: 0 ошибок, 0 предупреждений. 6 Core + 54 Windows-проверки успешны локально и в GitHub Actions.
Core проверяет кольцевой буфер, хронологию, замороженный снимок, истечение кадров, конкурентное чтение и горячие клавиши.
Windows-проверки охватывают JPEG/PNG, регистрацию и конфликт клавиш, неизменность истории, выбор кадра менее 100 мс, редактор, темы и размещение окон.
Новые проверки декодируют H.264 при 15/30/60 FPS и AAC с синтетическим сигналом, проверяют сохранение готового MP4 при блокировке файла, сохранность существующего назначения, паузу/продолжение, экспорт выбранного диапазона из RAM, фиксацию снимка, очистку при блокировке, просмотр, закрепление и OCR синтетического текста.
Дополнительно проверены вытеснение плохо сжимаемых кадров при лимите 64 МБ и сброс последовательности после изменения размера источника.

[GitHub Actions: сборка, тесты, упаковка и установщик](https://github.com/domovoyproj/ReplayKit/actions/runs/37523971101) успешно проверил установку без администратора, запуск self-contained приложения, штатное завершение и удаление на чистой машине.

## Реальный экран и окно

После разблокировки Windows выполнен `--capture`: 76 Windows-проверок, включая 54 обычные.
DXGI захватывал видимое тестовое окно при 1920×1080. Первый кадр был полноценным; восемь последовательных кадров и фоновая история сохранили контрольный цвет: RGB 218,53,96 при ожидаемом 218,52,96 (JPEG).
Записанный с экрана MP4 декодирован: размеры и контрольный цвет подтверждены. История продолжала работать во время видео; остановка и имитация блокировки корректно завершили файл.
Windows Graphics Capture отдельно проверен на окне, полностью перекрытом другим непрозрачным окном: получены пиксели именно выбранного окна.
Это закрывает прежнюю незавершённую проверку чёрного стартового кадра. DXGI игнорирует обновления одного курсора с LastPresentTime=0, а не принимает их за новую поверхность рабочего стола.

## Длительная запись и память

30-минутный real-time прогон: одновременно CaptureService, MP4, секундная история и 60-секундный RAM-видеобуфер. Источник синтетический, 1024×640, видео 30 FPS, звук выключен.
Готовый H.264 полностью декодирован: 54 032 кадра, длительность 1801,07 секунды. Запись не прерывалась; история сохраняла 60 кадров.
Private memory: 196 МБ после прогрева, 212 МБ перед остановкой; разница +16 МБ, без непрерывного роста. Сжатый видеобуфер занимал около 6 МБ на однотонном источнике.
Отдельный тест случайного шума подтвердил вытеснение при достижении лимита 64 МБ. Прогон не заменяет долговременную проверку физических аудиоустройств и A/V-синхронизации.

## Интерфейс и ограничения

Просмотрены синтетические рендеры истории в двух темах, настроек, редактора, видеобуфера, закреплённого кадра и сравнения. Файлы находятся в игнорируемом `artifacts/qa/`.
Готовые превью переключались быстрее 100 мс, в последних локальных прогонах максимум около 16 мс с обновлением WPF layout. Первое декодирование всей истории и задержка физического дисплея в это измерение не входят.

Не выполнена полная аппаратная матрица Windows 10/11, DPI 100–250%, сна, вертикальных/HDR-мониторов, физических микрофонов и звуковых устройств. WGC использует BGRA8; специальное HDR tone mapping не реализовано.
Частоты 15/30/60 — целевые. При перегрузке очередь MP4 отбрасывает старые кадры. Видеобуфер хранит MJPEG и PCM в RAM; H.264/AAC создаются при явном сохранении. Лимит памяти относится к живому сжатому буферу, не ко всему процессу.
Secure desktop и защищённый контент не захватываются. При аварийном завершении незавершённый MP4 может быть непригоден; готовый MP4 сохраняется даже при ошибке переноса в выбранный файл.
Исполняемые файлы не подписаны сертификатом издателя.

## Graphify

Использованы `extract . --code-only`, `query`, `affected`, `god-nodes`, `explain`, `diagnose multigraph` и `export html`. Graphify 0.9.77, AST token cost: 0. `graphify-out/` остаётся исключённым из Git.
Граф содержит пять самоссылок, без dangling/missing endpoints и схлопывания разных рёбер. Инструмент сохраняет узлы двух существующих файлов вне текущего сканирования и не извлекает символы некоторых PowerShell-файлов. Ранее он также сообщал о совпадающих ID пространств имён. Эти ограничения не скрываются: граф помогает находить связи, поведение подтверждается кодом, сборкой и тестами.
