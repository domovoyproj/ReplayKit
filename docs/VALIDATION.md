# Проверка ReplayKit 1.0.0

6 октября 2026 года.

Локальная Release-сборка .NET 8: без ошибок и предупреждений.

## Автоматические проверки

6 проверок Core: обороты кольцевого буфера, хронологический порядок, неизменность снимка после записи и очистки, исключение кадров старше минуты и кадров из будущего, параллельное чтение/запись, валидация горячих клавиш.

16 Windows-проверок: JPEG в RAM, исходные размеры, PNG без изменения декодированных пикселей, регистрация/конфликт/обмен глобальных сочетаний, 60 готовых превью, фиксация истории, крайние позиции таймлайна, выбор кадра <100 мс, непрозрачное скрытие, отмена/повтор, обрезка в исходных пикселях.

Отдельная локальная проверка реального DXGI: Intel UHD Graphics 620, 1920×1080, JPEG получен в RAM; рабочий стол на диск не записывался.
Максимальное время выбора готового кадра в последней локальной проверке — 17,62 мс, включая обновление WPF layout. Это измерение выбора превью; первое декодирование истории и время отображения физическим монитором в него не входят.

GitHub Actions дополнительно компилирует Inno Setup и проверяет установку в HKCU, запуск self-contained приложения, штатное завершение через `--quit`, удаление установленных файлов.
Результат конкретного запуска доступен в [Actions](https://github.com/domovoyproj/ReplayKit/actions).

## Визуальная проверка

Изображения интерфейса со синтетическим кадром: `artifacts/qa/history-dark.png`, `history-light.png`, `editor-dark.png`.
Проверены читаемость, скругления, тени, ползунок, лента превью и панели действий. При узком окне действия истории переходят на вторую строку; инструменты редактора переносятся.

Per-Monitor V2 и размещение окна в физических координатах реализованы. Полная ручная матрица Windows 10/11, смешанных DPI 100–250%, вертикальных/HDR-мониторов, сна и блокировки на разных драйверах не выполнена и не заменяется синтетическими тестами.
Исполняемые файлы не подписаны сертификатом издателя.

## Graphify

Установлен `graphifyy 0.9.77`. Использованы `extract . --code-only`, `query`, `affected`, `god-nodes`, `explain`, `cluster-only`, `export html` и `diagnose multigraph`.
`graphify-out/` исключён из Git. AST не извлекает символы из некоторых PowerShell и top-level файлов; связи INFERRED остаются предположениями.
Диагностика графа обнаруживает две самоссылки вызовов, без потерянных концов рёбер или схлопывания разных рёбер. Graphify также сообщает о сохранённых узлах двух существующих файлов вне текущего сканирования; эти ограничения инструмента не скрываются.
Граф используется для навигации по связям, а поведение проверяется сборкой и тестами.
