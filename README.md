# ReplayKit

Последняя минута экрана — всегда под рукой. Локальное WPF-приложение для Windows 10 2004+ / Windows 11 x64, C# / .NET 8.

## Установка

Скачайте установщик или portable ZIP в [GitHub Releases](https://github.com/domovoyproj/ReplayKit/releases/latest).
Установщик работает без прав администратора и размещает приложение в `%LOCALAPPDATA%\Programs\ReplayKit`.
В portable ZIP распакуйте **все** файлы в одну папку и запустите `ReplayKit.exe`: отдельный .NET не нужен.
Закрытие окна оставляет приложение в трее. Для завершения выберите «Выйти» в меню трея.

## Использование

`Ctrl+Shift+R` открывает историю. `Ctrl+Shift+P` включает и приостанавливает буфер скриншотов.
`Ctrl+Shift+V` начинает/останавливает MP4, `Ctrl+Shift+B` открывает видеобуфер.
Все четыре сочетания меняются в настройках; занятые сочетания отклоняются.
Приложение сохраняет в RAM один полноразмерный JPEG с качеством 88% в секунду и хранит до 60 кадров.
Выберите монитор, секунду или превью. История фиксируется при открытии; кнопка ↻ создаёт новый снимок истории.
На старте, после переключения монитора или перерыва в записи доступно меньше минуты. Пропущенные секунды показывают ближайший имеющийся кадр; его точное время отображается под изображением.

| Клавиши | Действие |
| --- | --- |
| ← / → | На одну секунду |
| Shift + ← / → | На пять секунд |
| Колесо над таймлайном | Перемещение по истории |
| Home / End | Самый старый / последний кадр |
| Ctrl+C / Ctrl+S | Копировать / сохранить PNG |
| E / Esc | Редактировать / закрыть |
| Ctrl+Z / Ctrl+Y в редакторе | Отменить / повторить |

Редактор работает с исходным разрешением: перо, стрелки, рамки, маркер, текст, нумерованные отметки, обрезка и непрозрачное скрытие.
Для текста щёлкните по изображению, введите текст и нажмите Enter. Esc отменяет ввод.
Для обрезки выделите прямоугольник. Копирование и сохранение включают все правки; исходный кадр истории сохраняется.
Светлая, тёмная и системная темы доступны в настройках. Автозапуск можно отключить там же.

В меню **Ещё**: закрепить кадр поверх окон, выбрать первый кадр и сравнить его со вторым, локально распознать текст и скопировать его. OCR использует установленные в Windows языки распознавания; облака не нужны.
Там же можно выбрать окно или экран через системный выбор Windows Graphics Capture. Для прямоугольной области сначала выберите монитор, затем **Ещё → Выделить область монитора** и выделите её на кадре. Координаты соответствуют исходным пикселям.
Для возврата используйте **Захватывать весь монитор**. Выбранное окно может захватываться за другими окнами; свёрнутое или защищённое окно может перестать выдавать кадры.

## Запись видео

Нажмите **● Видео** в окне истории или «Начать / остановить видео» в трее.
Выберите место сохранения MP4 — после этого начинается запись выбранного источника.
Нажмите **■ Стоп**, чтобы завершить и сохранить файл. Красная иконка трея и таймер показывают активную запись.
Закрытие окна истории оставляет видео работающим; остановить его можно из трея.

Видео: H.264 в MP4. В настройках доступны 15/30/60 кадров/с, исходный размер или ширина до 1920/1280 пикселей и три уровня качества.
Системный звук и микрофон включаются отдельно, с независимой громкостью 0–200%; по умолчанию оба выключены. Аудио сохраняется как AAC, 48 кГц, стерео. Используются устройства Windows по умолчанию на момент старта записи.
Плавающая панель показывает таймер, паузу/продолжение и остановку. Пауза исключается из длительности ролика. Панель исключена из захвата.
Кодирование выполняет встроенная Media Foundation Windows; FFmpeg и дополнительные программы не требуются.
Фактическая частота зависит от разрешения и производительности компьютера. Нечётные размеры обрезаются на один пиксель для H.264.
Буфер скриншотов продолжает работать независимо от видео; его пауза не останавливает видео.
На время видео изменение источника и настроек отключено. Блокировка, сон, изменение экрана или штатный выход завершают запись.
При сбое питания или принудительном завершении незавершённый MP4 может быть непригоден для воспроизведения.

Если готовый MP4 не удаётся перенести в выбранное место, он сохраняется рядом с ним как `*.replaykit-*.mp4`. Приложение показывает путь и при ручной остановке предлагает другое место. Готовая запись не удаляется при такой ошибке.

## Видеобуфер

Включите **Настройки → Хранить последние секунды видео**. Выберите 15, 30 или 60 секунд и лимит сжатого буфера 64–1024 МБ. Экономичный режим — до 960 пикселей по ширине и 15 кадров/с; обычный — до 1920 пикселей и 30 кадров/с.
Сжатые JPEG-кадры и выбранный звук хранятся в RAM, без временных файлов. Это независимый видеобуфер MJPEG; готовый файл экспортируется в H.264/MP4. При достижении лимита самые старые кадры удаляются раньше указанной длительности.
Нажмите **Ctrl+Shift+B**, выберите начало и конец, просмотрите фрагмент со звуком или без него и нажмите **Сохранить MP4**. До выбора файла изображения и звук не записываются на диск.
Просмотр фиксирует снимок буфера, пока фоновая запись продолжается. Лимит относится к живому сжатому буферу; открытый снимок, превью, история скриншотов и редактор занимают дополнительную память.
Изменение размера источника начинает новую последовательность кадров для совместимого экспорта.

## Локальные данные

Никаких сетевых запросов, телеметрии, облака или автоматических файлов изображений.
Захват, JPEG, превью и правки находятся только в памяти процесса. PNG создаётся только по команде «Сохранить».
MP4 записывается только после явного выбора файла: во время записи создаётся временный файл рядом с ним; по команде «Стоп» он завершается и переносится в выбранный файл.
Буфер обмена передаётся Windows по явной команде «Копировать»; дальнейшее хранение определяется настройками Windows.
Настройки без изображений: `%LOCALAPPDATA%\ReplayKit\settings.json`. После выхода история исчезает.
При блокировке Windows живые буферы очищаются и захват приостанавливается; при разблокировке возобновляется. Уже открытый снимок истории остаётся в памяти до закрытия его окна.
Окна ReplayKit исключаются из захвата на Windows 10 2004+ и Windows 11.

DXGI требует обычного интерактивного рабочего стола и поддерживаемого видеодрайвера.
Secure desktop, DRM-контент и некоторые удалённые сеансы не захватываются; ошибки видны в окне и трее, захват автоматически повторяется.
Расход RAM зависит от разрешения и содержимого: JPEG-буфер до 60 кадров, экранные превью до 1280 px и ограниченная история правок редактора.
Первое открытие может потребовать подготовки превью; последующее переключение использует готовые изображения без декодирования.

## Сборка и проверка

На машине разработчика нужен .NET 8 SDK. Для установщика — Inno Setup 6.

```powershell
dotnet build ReplayKit.sln -c Release
dotnet run --project tests/ReplayKit.Tests -c Release
dotnet run --project tests/ReplayKit.WindowsTests -c Release
# Дополнительная проверка реального DXGI в локальном интерактивном сеансе:
dotnet run --project tests/ReplayKit.WindowsTests -c Release -- --capture
# 30-минутная проверка записи и RAM на синтетических кадрах:
dotnet run --project tests/ReplayKit.WindowsTests -c Release -- --soak
./scripts/build.ps1
```

`artifacts/` содержит self-contained portable ZIP, установщик (при наличии ISCC) и SHA256SUMS.
WPF-проверки создают изображения интерфейса и MP4 **с синтетическими тестовыми кадрами**, затем декодируют видео и проверяют цвета, ориентацию и временные метки.
Дополнительный `--capture` временно покрывает выбранный монитор тестовым окном, проверяет реальные пиксели DXGI и запись этого тестового окна. Нужен разблокированный сеанс; автозапуск не меняется.
GitHub Actions собирает, проверяет и упаковывает Windows-версию, затем проверяет установку, запуск и удаление на чистом runner. Новая версия в `main` или тег `v2.0.0` публикует GitHub Release после всех проверок.
Бинарные файлы не подписаны сертификатом издателя.

## Архитектура и Graphify

- `ReplayKit.Core`: кадр, потокобезопасный кольцевой буфер, описание сочетания клавиш.
- `CaptureService`: владеет DXGI/WGC и отправляет кадры в ограниченные очереди.
- `HistoryEncoder`: отдельный поток JPEG-истории; `VideoSession`: отдельный поток MP4/AAC; `ReplayBuffer`: отдельный поток сжатия видеобуфера и контроль RAM.
- `AudioMixer`: WASAPI, независимые входы и громкость; `TextRecognition`: локальный Windows OCR.
- Остальные сервисы: глобальные клавиши Win32, темы, PNG/clipboard, настройки и размещение окон.
- `ReplayKit/Views`: замороженная история, настройки, растровый редактор с ограничением памяти отмены.
- `App`: один экземпляр, активация второго запуска, трей, автозапуск и события Windows.
