# ReplayKit

Последняя минута экрана — всегда под рукой. Локальное WPF-приложение для Windows 10/11 x64, C# / .NET 8.

## Установка

Скачайте установщик или portable ZIP в [GitHub Releases](https://github.com/domovoyproj/ReplayKit/releases/latest).
Установщик работает без прав администратора и размещает приложение в `%LOCALAPPDATA%\Programs\ReplayKit`.
В portable ZIP распакуйте **все** файлы в одну папку и запустите `ReplayKit.exe`: отдельный .NET не нужен.
Закрытие окна оставляет приложение в трее. Для завершения выберите «Выйти» в меню трея.

## Использование

`Ctrl+Shift+R` открывает историю. `Ctrl+Shift+P` включает запись и паузу.
Оба сочетания меняются в настройках; занятые сочетания отклоняются.
Приложение сохраняет в RAM один полноразмерный JPEG с качеством 88% в секунду и хранит до 60 кадров.
Выберите монитор, секунду или превью. История фиксируется при открытии; кнопка ↻ создаёт новый снимок истории.
На старте, после переключения монитора или перерыва в записи доступно меньше минуты. Пропущенные секунды показывают ближайший имеющийся кадр; его точное время отображается под изображением.

| Клавиши | Действие |
| --- | --- |
| ← / → | На одну секунду |
| Shift + ← / → | На пять секунд |
| Колесо над таймлайном | Перемещение по истории |
| Home / End | Самый старый / последний кадр |
| Ctrl+C / Ctrl+S | Копировать / сохранить PNG |
| E / Esc | Редактировать / закрыть |
| Ctrl+Z / Ctrl+Y в редакторе | Отменить / повторить |

Редактор работает с исходным разрешением: перо, стрелки, рамки, маркер, текст, обрезка и непрозрачное скрытие.
Для текста щёлкните по изображению, введите текст и нажмите Enter. Esc отменяет ввод.
Для обрезки выделите прямоугольник. Копирование и сохранение включают все правки; исходный кадр истории сохраняется.
Светлая, тёмная и системная темы доступны в настройках. Автозапуск можно отключить там же.

## Локальные данные

Никаких сетевых запросов, телеметрии, облака или автоматических файлов изображений.
Захват, JPEG, превью и правки находятся только в памяти процесса. PNG создаётся только по команде «Сохранить».
Буфер обмена передаётся Windows по явной команде «Копировать»; дальнейшее хранение определяется настройками Windows.
Настройки без изображений: `%LOCALAPPDATA%\ReplayKit\settings.json`. После выхода история исчезает.
При блокировке Windows буфер очищается и захват приостанавливается; при разблокировке возобновляется.
Окна ReplayKit исключаются из захвата на Windows 10 2004+ и Windows 11.

DXGI требует обычного интерактивного рабочего стола и поддерживаемого видеодрайвера.
Secure desktop, DRM-контент и некоторые удалённые сеансы не захватываются; ошибки видны в окне и трее, захват автоматически повторяется.
Расход RAM зависит от разрешения и содержимого: JPEG-буфер до 60 кадров, экранные превью до 1280 px и ограниченная история правок редактора.
Первое открытие может потребовать подготовки превью; последующее переключение использует готовые изображения без декодирования.

## Сборка и проверка

На машине разработчика нужен .NET 8 SDK. Для установщика — Inno Setup 6.

```powershell
dotnet build ReplayKit.sln -c Release
dotnet run --project tests/ReplayKit.Tests -c Release
dotnet run --project tests/ReplayKit.WindowsTests -c Release
# Дополнительная проверка реального DXGI в локальном интерактивном сеансе:
dotnet run --project tests/ReplayKit.WindowsTests -c Release -- --capture
./scripts/build.ps1
```

`artifacts/` содержит self-contained portable ZIP, установщик (при наличии ISCC) и SHA256SUMS.
WPF-проверки создают изображения интерфейса **с синтетическим тестовым кадром**, не сохраняют захваченный рабочий стол и не меняют автозапуск.
GitHub Actions собирает, проверяет и упаковывает Windows-версию, затем проверяет установку, запуск и удаление на чистом runner. Тег `v1.0.1` публикует GitHub Release.
Бинарные файлы не подписаны сертификатом издателя.

## Архитектура и Graphify

- `ReplayKit.Core`: кадр, потокобезопасный кольцевой буфер, описание сочетания клавиш.
- `ReplayKit/Services`: DXGI/D3D11, таймер захвата, глобальные клавиши Win32, темы, PNG/clipboard, настройки и размещение окон.
- `ReplayKit/Views`: замороженная история, настройки, растровый редактор с ограничением памяти отмены.
- `App`: один экземпляр, активация второго запуска, трей, автозапуск и события Windows.

```powershell
uv tool install graphifyy
graphify extract . --code-only
graphify query "CaptureService DxgiCapture FrameBuffer HistoryWindow"
graphify affected src/ReplayKit/Services/DxgiCapture.cs
graphify god-nodes
graphify explain CaptureService
graphify cluster-only . --no-label
graphify export html
```

Граф хранится локально в `graphify-out/`, исключённом из Git. `AGENTS.md` закрепляет Graphify для дальнейшего анализа.
AST-граф содержит как извлечённые, так и предположенные связи; он помогает навигации, а проверка поведения выполняется сборкой и тестами.
